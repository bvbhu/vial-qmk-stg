# tl12blef103 蓝牙配对与连接操作说明

本文说明 tl12blef103 键盘（STM32F103C8T6 + CH582F/CH591R 蓝牙桥）的**蓝牙配对、连接、多主机切换**操作方法。

配套文档：`WIRING.md`（接线与烧录）。本文只讲怎么用，不讲怎么焊、不讲代码。

> 本文按默认 keymap 的实际布局编写（`keymaps/default/keymap.c`）：
> 主层是字母键、无线功能键集中在功能层，二者用空格位的 `MO(1)` 切换。若你改了键位，
> 下文所有「按住功能层 + 按无线键」的操作请对应到你实际映射的物理键上。

---

## 一、默认固件按键布局

默认固件共 2 层（12 键 = 2 行 × 6 列）：

**Layer 0（主层，日常打字）**

| 键位 | 功能 |
|---|---|
| 第 1 行 6 键 | `A` `B` `C` `D` `E` `F` |
| 第 2 行前 5 键 | `G` `H` `I` `J` `K` |
| 第 2 行最后 1 键（空格位） | `MO(1)` —— **按住切入功能层**，松开回到主层 |

**Layer 1（功能层，无线与输出切换）**——按住空格位（MO(1)）时生效：

| 键位 | 功能 |
|---|---|
| `USB_TOG` | 松手：关闭蓝牙广播 → 切到 USB 输出 |
| `BLE_SW1` | 短按：蓝牙通道 1 回连；长按：通道 1 配对 |
| `BLE_SW2` | 短按：蓝牙通道 2 回连；长按：通道 2 配对 |
| `BLE_SW3` | 短按：蓝牙通道 3 回连；长按：通道 3 配对 |
| `RF_TOG` | 短按：切 2.4G（并关闭蓝牙广播）；长按：2.4G 配对 |
| `NK_TOGG` | 切换 NKRO（全键无冲）开/关 |

> 12 键键盘上无线键不常驻主层：**蓝牙操作 = 按住空格位（MO(1)）不放，再短按/长按对应的无线键**。
> 主层全是字母键，日常打字直接按即可。

若需要把无线功能改到别的物理键（或加一层专门放无线键），用 [Vial](https://get.vial.today/) 改即可，**无需重新编译固件**：

1. USB 线连接键盘与电脑（此时是 USB 模式）。
2. 打开 Vial → 键盘被识别。
3. 点顶部 **Keymap** 页 → 点一个要改的键位。
4. 在下方键码列表里点 **无线** 标签页（原「蓝牙/无线」），找到下表里的按钮，点一下写入。
5. 写入后立即生效。

### 1.1 Vial「无线」页里的按钮

Vial 页面上显示的是**按钮图标文字**，按这些文字找即可（均为本固件真实实现的键码）：

| Vial 上的按钮 | 对应固件键码 | 功能 |
|---|-------------|--------------|
| `BLE1` | `BLE_SW1`（= `BT_PRF1`） | 蓝牙通道 1：短按回连、长按配对 |
| `BLE2` | `BLE_SW2`（= `BT_PRF2`） | 蓝牙通道 2：短按回连、长按配对 |
| `BLE3` | `BLE_SW3`（= `BT_PRF3`） | 蓝牙通道 3：短按回连、长按配对 |
| `USBTG` | `USB_TOG`（= `OU_USB`） | 切回 USB（有线） |
| `2.4G` | `RF_TOG`（= `OU_2P4G`） | 切 2.4G（需配套 2.4G 接收器） |
| `BLE OFF` | （= `OU_NONE`） | 关闭无线输出（断开蓝牙/关广播） |

> GUI 的「无线」面板已按本固件实现收窄：**只列上面 6 个真实可用的按钮**。
> 旧版（上游）面板里的 `Auto Host` / `Next Host` / `Prev Host` / `BT Unpair` / `BT4` / `BT5`
> 等本固件均为空实现，已从面板移除；若用旧版 GUI 看到它们，按了不会有反应。

### 1.2 哪些键真的有用

- **无线功能层**：`USB_TOG`、`BLE_SW1-3`、`RF_TOG`、`NK_TOGG` 都是真实实现的（走自定义蓝牙驱动），可用。
- **三通道**：只有通道 1/2/3（`BLE_SW1-3`）有效，没有 `BT4`/`BT5`。
- **电池与关广播** 不在「无线」页：见 §1.3，需到「用户按键」页映射。

### 1.3 关于电池与关闭广播

这两个功能**不在无线页里**，需要到「用户按键」页找（通用用户键码槽位）：

| Vial 里找 | 功能 |
|---|---|
| 第 30 个用户按键（`QK_USER_30`） | 报电量：在当前输出通道打出一行 `Bat: 85% 3950mV` |
| 第 29 个用户按键（`QK_USER_29`） | 只关闭蓝牙广播（不切走当前通道） |
| 第 28 个用户按键（`QK_USER_28`） | **无效**，按了没反应（上游蓝牙复位预留） |

> 这三个显示为通用「用户按键」，看起来跟蓝牙无关，但功能真实。默认 keymap 未放置它们，
> 需要的话用 Vial 把对应用户键码映射到任意键。

### 1.4 12 键映射建议

小键盘只有 12 个键，建议：

- **主层放字母/常用键**（默认固件即如此：A-K + 空格位 MO(1)）。
- **功能层放无线键**（默认固件即如此：`USB_TOG`/`BLE_SW1-3`/`RF_TOG`/`NK_TOGG`）。
- 若不想按住空格切层，也可以把 `BLE_SW1`（蓝牙通道 1）直接放主层——短按重连、长按配对，单键搞定。
- 默认支持 4 层，够用。

### 1.5 操作时长定义（重要）

`BLE_SW1` / `BLE_SW2` / `BLE_SW3` 和 `RF_TOG` 这**四个键是时长敏感**的，固件按按住时间区分动作：

| 按住时长 | 动作 |
|---|---|
| < 30ms | 忽略（太短，抖动） |
| 30ms ~ 800ms | **短按**：开**非配对**广播 / 普通模式 |
| 800ms ~ 1000ms | 忽略（死区） |
| ≥ 1000ms | **长按**：开**配对**广播 / 配对模式 |

也就是说：想配对就**按住超过 1 秒**，想重连就**轻点一下**。中间那 800~1000ms 是不响应区间，别卡在那儿。

#### 哪些按键受时长影响？

| 按键 | 是否时长敏感 | 触发时机 |
|---|---|---|
| `BLE_SW1` / `BLE_SW2` / `BLE_SW3` | ✅ 是 | 松手时按短按（30~800ms）/ 长按（≥1000ms）区分 |
| `RF_TOG` | ✅ 是 | 同上 |
| `USB_TOG` | ❌ 否 | **仅松开时**执行 |
| 关闭广播（用户键 29） | ❌ 否 | **仅松开时**执行 |
| 报电量（用户键 30） | ❌ 否 | **按下时**执行 |

> `USB_TOG` 不看时长，长按短按效果一样，都在**松手瞬间**动作。所以切 USB 时按住不放是不会切换的，**必须松开**。

## 二、首次配对流程

以下以「把键盘配对到电脑 A 的蓝牙，占用通道 1」为例。通道 1 在功能层 = `BLE_SW1`。

### 步骤

1. **确保键盘供电。** 插 USB 或装电池。首次建议插着 USB 做，方便排查。
2. **进入配对模式。** 默认布局下：**按住空格位（MO(1)）不放，同时按住 `BLE_SW1` 超过 1 秒**，然后一起松开。
   - **键盘只在接下来 30 秒内可被配对。**
3. **在电脑上添加设备。** 打开系统蓝牙设置 → 添加设备 → 选择键盘。
   - 不需要输配对码。
4. **等待连接建立。** 连上后即可打字。

> 💡 若键盘不止 12 键、你把 `BLE_SW1` 直接映射到了主层，则跳过空格位，直接**长按 `BLE_SW1` 超过 1 秒**即可。

### 配对窗口只有 30 秒

**广播超时固定 30 秒。** 超时后自动停播，需要重新长按。

> 好消息：**广播期间键盘不会休眠**。所以不用担心"按完键等两秒键盘睡了导致配对失败"。

### 配对不成功时的重试

直接**再执行一次长按**（MO(1) + `BLE_SW1` ≥ 1s）即可重新开 30 秒配对窗口。无需重启键盘。

### ⚠️ 别用短按做首次配对

**短按开的是"非配对广播"，只能让已经配过的设备重连。**

对一台**从没配过**的设备，短按广播会出现「看得见、连不上 / 连上没反应」。首次配对**必须长按**。

## 三、日常重连

配对完成后，键盘和电脑各自记住了对方，后续连接不需要再走配对流程。

### 3.1 短按重连（推荐）

默认布局下：**按住空格位（MO(1)）+ 短按**对应通道键（如 `BLE_SW1`）→ 键盘开始 30 秒广播 → 已配对的主机会自动认出并连上。

### 3.2 按键唤醒（自动重连）

键盘休眠或断开后，**按下任意一个普通按键**也会触发重连广播（前提：当前已是无线/蓝牙模式）。

所以正常使用中你不需要专门去按通道键——**随便敲个字母，键盘就自己找回来了**。

> 如果当前已经连着、或已经在广播，按普通键**不会打断现有连接**。可以放心用。
> 注意：主层全是字母键，恰好都符合"普通按键"；无线功能键本身（`BLE_SW1-3`/`RF_TOG`/`USB_TOG` 等）不触发自动广播。

### 3.3 电脑侧主动连接

如果键盘在广播（短按过通道键），也可以在电脑的蓝牙设置里点键盘名称手动连接。

## 四、三通道主机管理

键盘支持 **3 个蓝牙主机**（通道 1 / 2 / 3），对应 `BLE_SW1` / `BLE_SW2` / `BLE_SW3`。

| 功能层键 | 通道 |
|---|---|
| `BLE_SW1` | 主机 1 |
| `BLE_SW2` | 主机 2 |
| `BLE_SW3` | 主机 3 |

### 用法

- **短按**通道键 = 切到该通道并开 30 秒非配对广播（用于已配对的设备重连）。
- **长按**通道键 = 切到该通道并开 30 秒配对广播（用于把该通道配给一台新设备）。

默认布局下两者都需**先按住空格位（MO(1)）**再操作。

### 典型场景

```
电脑（通道1）   平板（通道2）   手机（通道3）
    BLE_SW1         BLE_SW2         BLE_SW3
```

- 第一次：长按 `BLE_SW1` → 配电脑；长按 `BLE_SW2` → 配平板；长按 `BLE_SW3` → 配手机。
- 之后：短按对应通道键即可在三台设备间切换，各自独立记忆，互不影响。

> **配对信息保存在蓝牙桥模块里**，不在主控芯片里。所以重新烧录固件**不会**丢失配对记录。

> 只有 3 个通道，没有第 4/5 通道。

## 五、USB / 2.4G / 蓝牙输出切换

| 功能层键 | 行为 |
|---|---|
| `USB_TOG` | 松开时：关闭蓝牙广播 → 切到 USB |
| `BLE_SW1` | 短按：开 30 秒非配对广播 → 切到蓝牙通道 1；长按：配对广播 |
| `RF_TOG` | 短按：切 2.4G；长按：进入 2.4G 配对 |

要点：

- **上电默认是 USB 模式。** 插着 USB 线开机不会自动走蓝牙，要按 `BLE_SW1`（或其它通道键）切过去。
- `USB_TOG` 会主动关闭蓝牙广播，所以切回 USB 后广播就停了。想再用蓝牙得重新按通道键。
- `RF_TOG` 切 2.4G 时同样先关闭蓝牙广播。
- 关闭广播（用户键 29）只关广播、不动通道，适合"我想停播但保持蓝牙模式"。

## 六、超时、休眠与状态判读

### 6.1 休眠行为

| 项目 | 值 | 说明 |
|---|---|---|
| 空闲进入休眠 | **10 秒** | 10 秒无操作即休眠 |
| 广播期间 | **不休眠** | 30 秒配对/重连窗口内保持唤醒 |
| Vial 连接中 | **不休眠** | 用 Vial 改键位时不会睡 |

**有线永不休眠**：USB 模式下键盘不会睡。

休眠后按下任意键即可唤醒，唤醒后如果原本是已连接状态会自动恢复。

### 6.2 状态判读

**本键盘没有蓝牙状态指示灯。** RGB 灯只跑灯效，不反映连接状态。

要确认状态只能看电脑/手机端的蓝牙界面：
- 显示**已连接** → 可以打字；
- 显示**已配对但未连接** → 短按一下对应通道键；
- **完全看不到设备** → 长按通道键重新开配对广播。

### 6.3 电池信息

按下报电量键（用户键 30）会在当前输出通道上打出一行字符串：

```
Bat: 85% 3950mV
```

低电量时键盘会自动降低蓝牙上报频率以省电。

## 七、故障排查

### 7.1 电脑完全搜不到键盘名

1. **确认真的在广播。** 长按通道键必须**超过 1 秒**；短按开的非配对广播对未配对设备是不可见的。
2. **确认切到了蓝牙模式。** 如果刚插上 USB 没按过 `BLE_SW1`，还是 USB 模式，蓝牙根本没开。
3. **过了 30 秒窗口。** 重新长按。

### 7.2 能搜到但连不上 / 连上没输入

- **首次配对用了短按。** 短按是非配对广播，新设备连不上。**必须长按**。
- 通道串了：确认按的是你要用的那个 `BLE_SW1`/`BLE_SW2`/`BLE_SW3`。
- **反复"连上又断开"** → 见 7.7，这是 Windows 的已知行为，必须在电脑侧清理。

### 7.3 想「恢复出厂 / 清空配对」怎么办

Vial 里没有可用的「解除配对」按钮（`BT Unpair` 为空实现），用户键 28 同样无效。

**目前清空配对的做法：**
1. 在电脑/手机侧删除该键盘的蓝牙配对记录；
2. 长按对应通道键，重新走配对流程（新配对会覆盖该通道旧记录）。

### 7.4 电池读数不准 / 永远 0%

- 用 USB 供电时电量保护逻辑会被跳过，读数仅供参考。
- 若一直为 0%，按 `WIRING.md` 核对接线。

### 7.5 刚上电 500ms 内蓝牙不响应

键盘启动后需要约 **0.5 秒**下发一次蓝牙配置。

**上电后约 0.5 秒内按蓝牙键可能没反应，属于正常现象。等 1 秒再操作。**

### 7.6 所有蓝牙操作都无效

按 `WIRING.md` 检查键盘与蓝牙桥模块之间的接线：

- 串口是**交叉接线**（键盘 TX → 桥 RX，键盘 RX ← 桥 TX）；
- 波特率 **128000 8N1**；
- **必须共地**。

`TX`/`RX` 接成直连会完全无数据。

### 7.7 ⚠️ Windows：反复「连上又断开」（Reason:8）

**症状**：桥日志里看到

```
hidDevDisconnected: secure:0 bond:N
Disconnected.. Reason:8
```

反复短按 / 长按重配都一样；有时连续失败几次后又能连上。

**原因（不在键盘侧）**：电脑记住了旧密钥，键盘侧保存的已经不是同一把（或已被后来一次配对覆盖）。键盘按蓝牙规范工作在**等待主机发起配对**的模式，不会主动去重新配对；电脑又认为"这台我已经配过了"，于是反复拿旧密钥握手、反复被链路层拒绝（`Reason:8` = 找不到对应密钥）。

这是 **Windows 侧的配对缓存问题**。键盘固件无法绕过，也不应该绕过——为了让主机重配而改自己的蓝牙地址属于偏离规范的做法（ZMK 等主流固件全程不换址）。

**处理办法（顺序不能反）**：

1. **先在电脑的蓝牙设置里删除该键盘条目**：设置 → 蓝牙和其他设备 → 已配对的设备 → 找到键盘名（槽位名带后缀，如 `StuG KB BT-1` 对应通道 1、`-2` 对应通道 2、`-3` 对应通道 3）→ 删除。**只删你要重新配的那个通道**。
2. **再长按对应通道键 ≥1 秒**，开 30 秒配对窗口。
3. 在电脑蓝牙里添加设备并选择该键盘。此时它是一台"从未配对过"的设备，会正常走完整配对流程。

> ⚠️ **只长按而不先删除电脑条目是无效的**——键盘侧的"重新配对广播"不能让一台认为已配对的主机重新发起配对。这也是反复失败最常见的原因。
>
> 另一台电脑 / 手机同理：先在主机侧"忘记设备"再长按重配。手机通常能正确清掉缓存；若仍反复断开，确认手机已忘记该设备，并关闭再打开手机蓝牙。

## 八、速查卡

```
【首次配对某台设备（通道 N）】
  默认布局：按住空格位(MO1) + 按住 BLE_SW<N>  >1 秒
  然后 30 秒内在电脑/手机蓝牙里添加设备

【已配对设备重连】
  默认布局：按住空格位(MO1) + 短按 BLE_SW<N>   → 30 秒非配对广播
  或：随便按一个普通字母键                    → 自动重新广播（不会打断已有连接）

【反复「连上又断开」（Windows 常见）】
  ① 先在电脑蓝牙设置里删掉该键盘条目（只删对应通道那个，如 ...-2）
  ② 再长按 BLE_SW<N> ≥1 秒
  ③ 在电脑蓝牙里重新添加设备
  ⚠ 顺序不能反：只长按而不删电脑条目 = 白按，详见 7.7

【切回 USB】
  功能层按 USB_TOG（松手才生效）

【切 2.4G】
  功能层短按 RF_TOG（普通）/ 长按 RF_TOG（配对）

【NKRO】
  功能层按 NK_TOGG（切换全键无冲）

【查电量】
  映射「用户按键」第 30 个（QK_USER_30）→ 输出 "Bat: N% mV"

【注意】
  蓝牙操作 = 按住空格位(MO1) + 按无线键
  只有 BLE_SW1/2/3 有效，只有 3 个蓝牙通道
  短按 = 30~800ms，长按 = ≥1000ms，800~1000ms 无效
  上电 500ms 内不响应蓝牙操作
  10 秒无操作休眠；广播中（30 秒窗口）不休眠
  广播窗口固定 30 秒，超时需重按
  Vial「无线」页只有 BLE1/BLE2/BLE3/USBTG/2.4G/BLE OFF 可用
  清配对：去主机侧删记录后长按重新配对
```
