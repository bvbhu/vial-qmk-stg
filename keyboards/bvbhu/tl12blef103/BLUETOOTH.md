# tl12blef103 蓝牙配对与连接操作说明

本文说明 tl12blef103 键盘（STM32F103C8T6 + CH582F/CH591R 蓝牙桥）的**蓝牙配对、连接、多主机切换**操作方法。

配套文档：`WIRING.md`（接线与烧录）。本文只讲怎么用，不讲怎么焊、不讲代码。

---

## 一、默认固件已带蓝牙功能键

出厂默认键位共 2 层，**Layer 0 就是蓝牙/输出通道功能键**，可直接配对使用：

| 键位（Layer 0，左→右） | 功能 |
|---|---|
| 1 | `USB_TOG` 切 USB 输出 |
| 2 | `BLE_SW1` 蓝牙通道 1 |
| 3 | `BLE_SW2` 蓝牙通道 2 |
| 4 | `BLE_SW3` 蓝牙通道 3 |
| 5 | `BAT_INFO` 电量显示 |
| 6 | `RF_TOG` 切 2.4G |
| 7~12 | `KC_A` ~ `KC_E`、`KC_SPACE` |

Layer 1 才是 `F1` ~ `F12`。层切换键请按自己的键位配置（Vial 里可改）。

若需要把蓝牙功能键改到别的物理键上，用 [Vial](https://get.vial.today/) 改即可，**无需重新编译固件**：

1. USB 线连接键盘与电脑（此时是 USB 模式）。
2. 打开 Vial → 键盘被识别。
3. 点顶部 **Keymap** 页 → 点一个要改的键位。
4. 在下方键码列表里点 **蓝牙/无线** 标签页，找到下表里的按钮，点一下写入。
5. 写入后立即生效。

### 1.1 Vial「蓝牙/无线」页里的按钮

Vial 页面上显示的是**按钮图标文字**，按这些文字找即可：

| Vial 上的按钮 | 功能 |
|---|---|
| `Auto Host` | 自动选择输出（插 USB 走 USB，否则走无线） |
| `Next Host` | 循环切到下一个输出 |
| `Prev Host` | 循环切到上一个输出 |
| `No Host` | 关闭所有输出 |
| `USB Host` | 切到 USB 输出 |
| `2.4G Host` | 切到 2.4G 输出 |
| `BLE Host` | 切到蓝牙输出 |
| `BT Next` | 切到下一个蓝牙主机 |
| `BT Prev` | 切到上一个蓝牙主机 |
| `BT Unpair` | 解除当前蓝牙配对 |
| `BT1` | 蓝牙主机 1（通道 1） |
| `BT2` | 蓝牙主机 2（通道 2） |
| `BT3` | 蓝牙主机 3（通道 3） |
| `BT4` | 蓝牙主机 4（通道 4） |
| `BT5` | 蓝牙主机 5（通道 5） |

> **本键盘 + 本固件实际能用的，是下面这几个。** 其余按钮虽然能点，但键码为空实现，按了没反应（原因见 §1.2）。

| 推荐映射 | 按钮 | 作用 |
|---|---|---|
| ⭐ 最常用 | `BT1` / `BT2` / `BT3` | 三个蓝牙通道，配对 + 重连都靠它 |
| ⭐ 常用 | `USB Host` | 切回 USB |
| ⭐ 常用 | `BLE Host` | 直接切蓝牙（等于按 `BT1`） |
| 可选 | `2.4G Host` | 切 2.4G（需配套 2.4G 接收器） |

**`BT4` / `BT5` 对本键盘无效** —— 桥模块只支持 3 个蓝牙主机，`BT4`/`BT5` 按了没有任何反应。

### 1.2 哪些按钮真的有用

上游 QMK 官方文档把 `2.4G Host`、`BT1`~`BT5` 这类键码标注为 **(not yet implemented)**，在标准 QMK 里它们确实什么都不做。

但**本键盘用了自定义的蓝牙驱动，把这些按钮重新实现了一遍**，所以它们在本键盘上是真实可用的。文档下面讲的所有操作，都已按实际固件行为核对过。

简单记：**`BT1`/`BT2`/`BT3`、`USB Host`、`BLE Host`、`2.4G Host` 可用；`BT4`/`BT5`、`Auto/Next/Prev/No Host`、`BT Next`/`BT Prev`/`BT Unpair` 不可用。**

### 1.3 关于电池与关闭广播

这两个功能**不在蓝牙/无线页里**，Vial 的按钮文字也不带蓝牙字样，需要到**用户按键**页找（通用用户键码槽位）：

| 在 Vial 里找 | 功能 |
|---|---|
| 第 30 个用户按键 | 报电量：在电脑上打出一行 `Bat: 85% 3950mV` |
| 第 29 个用户按键 | 只关闭蓝牙广播（不切走当前通道） |
| 第 28 个用户按键 | **无效**，按了没反应 |

> 这三个在 Vial 里显示为通用「用户按键」编号，**看起来跟蓝牙无关**，但功能是真实的。如果 Vial 的列表里不好辨认，用「用户按键」标签页里按顺序数即可。

### 1.4 12 键映射建议

小键盘只有 12 个键，建议：

- **Layer 0 放蓝牙键**（默认固件即如此）：`USB_TOG`、`BT1`、`BT2`、`BT3`、`BAT_INFO`、`RF_TOG` 占前 6 键，其余放常用键。
- **Layer 1 放 `F1`~`F12`**（默认固件即如此）。
- 默认支持 4 层，够用。

### 1.5 操作时长定义（重要）

`BT1` / `BT2` / `BT3` 和 `2.4G Host` 这**四个按钮是时长敏感**的，固件按按住时间区分动作：

| 按住时长 | 动作 |
|---|---|
| < 30ms | 忽略（太短，抖动） |
| 30ms ~ 800ms | **短按**：开**非配对**广播 / 普通模式 |
| 800ms ~ 1000ms | 忽略（死区） |
| ≥ 1000ms | **长按**：开**配对**广播 / 配对模式 |

也就是说：想配对就**按住超过 1 秒**，想重连就**轻点一下**。中间那 800~1000ms 是不响应区间，别卡在那儿。

#### 哪些按键受时长影响？

| 按键 | 是否时长敏感 | 触发时机 |
|---|---|---|
| `BT1` / `BT2` / `BT3` | ✅ 是 | 分离短按（30~800ms）/ 长按（≥1000ms） |
| `2.4G Host` | ✅ 是 | 同上 |
| `BLE Host` | ❌ 否 | **仅松开时**执行，等价于 `BT1` 的短按动作 |
| `USB Host` | ❌ 否 | **仅松开时**执行 |
| 关闭广播（用户键 29） | ❌ 否 | **仅松开时**执行 |
| 报电量（用户键 30） | ❌ 否 | **按下时**执行 |

> `BLE Host` / `USB Host` / 关闭广播 不看时长，长按短按效果一样，都在**松手瞬间**动作。所以切 USB 时按住不放是不会切换的，**必须松开**。

## 二、首次配对流程

以下以「把键盘配对到电脑 A 的蓝牙，占用通道 1」为例。

### 步骤

1. **确保键盘供电。** 插 USB 或装电池。首次建议插着 USB 做，方便排查。
2. **进入配对模式。** **按住 `BT1` 超过 1 秒**再松开。
   - **键盘只在接下来 30 秒内可被配对。**
3. **在电脑上添加设备。** 打开系统蓝牙设置 → 添加设备 → 选择键盘。
   - 不需要输配对码。
4. **等待连接建立。** 连上后即可打字。

### 配对窗口只有 30 秒

**广播超时固定 30 秒。** 超时后自动停播，需要重新长按。

> 好消息：**广播期间键盘不会休眠**。所以不用担心"按完键等两秒键盘睡了导致配对失败"。

### 配对不成功时的重试

直接**再长按一次** `BT1` 即可重新开 30 秒配对窗口。无需重启键盘。

### ⚠️ 别用短按做首次配对

**短按 `BT1` 开的是"非配对广播"，只能让已经配过的设备重连。**

对一台**从没配过**的设备，短按广播会出现「看得见、连不上 / 连上没反应」。首次配对**必须长按**。

## 三、日常重连

配对完成后，键盘和电脑各自记住了对方，后续连接不需要再走配对流程。

### 3.1 短按重连（推荐）

**短按**对应的通道键（如 `BT1`）→ 键盘开始 30 秒广播 → 已配对的主机会自动认出并连上。

### 3.2 按键唤醒（自动重连）

键盘休眠或断开后，**按下任意一个普通按键**也会触发重连广播。

所以正常使用中你不需要专门去按通道键——**随便敲个字母，键盘就自己找回来了**。

> 如果当前已经连着、或已经在广播，按普通键**不会打断现有连接**。可以放心用。

### 3.3 电脑侧主动连接

如果键盘在广播（短按过通道键），也可以在电脑的蓝牙设置里点键盘名称手动连接。

## 四、三通道主机管理

键盘支持 **3 个蓝牙主机**（通道 1 / 2 / 3），对应 `BT1` / `BT2` / `BT3`。

| 按钮 | 通道 |
|---|---|
| `BT1` | 主机 1 |
| `BT2` | 主机 2 |
| `BT3` | 主机 3 |

### 用法

- **短按**通道键 = 切到该通道并开 30 秒非配对广播（用于已配对的设备重连）。
- **长按**通道键 = 切到该通道并开 30 秒配对广播（用于把该通道配给一台新设备）。

### 典型场景

```
电脑（通道1）   平板（通道2）   手机（通道3）
    BT1             BT2            BT3
```

- 第一次：长按 `BT1` → 配电脑；长按 `BT2` → 配平板；长按 `BT3` → 配手机。
- 之后：短按对应通道键即可在三台设备间切换，各自独立记忆，互不影响。

> **配对信息保存在蓝牙桥模块里**，不在主控芯片里。所以重新烧录固件**不会**丢失配对记录。

> **`BT4` / `BT5` 无效**，本键盘只有 3 个通道。

## 五、USB / 2.4G / 蓝牙输出切换

| 按键 | 行为 |
|---|---|
| `USB Host` | 松开时：关闭蓝牙广播 → 切到 USB |
| `BLE Host` | 松开时：开 30 秒非配对广播 → 切到蓝牙通道 1 |
| `2.4G Host` | 短按：切 2.4G；长按：进入 2.4G 配对 |
| 关闭广播（用户键 29） | 松开时：只关广播，保持当前通道 |

要点：

- **上电默认是 USB 模式。** 插着 USB 线开机不会自动走蓝牙，要按 `BLE Host` 或 `BT1` 切过去。
- `USB Host` 会主动关闭蓝牙广播，所以切回 USB 后广播就停了。想再用蓝牙得重新按通道键。
- `BLE Host` 等价于「短按 `BT1`」，都是通道 1。
- 「关闭广播」只关广播、不动通道，适合"我想停播但保持蓝牙模式"。

## 六、超时、休眠与状态判读

### 6.1 休眠行为

| 项目 | 值 | 说明 |
|---|---|---|
| 空闲进入休眠 | **10 秒** | 10 秒无操作即休眠 |
| 广播期间 | **不休眠** | 30 秒配对/重连窗口内保持唤醒 |
| Vial 连接中 | **不休眠** | 用 Vial 改键位时不会睡 |

**有线永不休眠**：USB 模式下键盘不会睡。

休眠后按下任意键即可唤醒，唤醒后如果原本是已连接状态会自动恢复。

### 6.2 状态判读

**本键盘没有蓝牙状态指示灯。** RGB 灯只跑灯效，不反映连接状态。

要确认状态只能看电脑/手机端的蓝牙界面：
- 显示**已连接** → 可以打字；
- 显示**已配对但未连接** → 短按一下对应通道键；
- **完全看不到设备** → 长按通道键重新开配对广播。

### 6.3 电池信息

按下报电量键（用户键 30）会在当前输出通道上打出一行字符串：

```
Bat: 85% 3950mV
```

低电量时键盘会自动降低蓝牙上报频率以省电。

## 七、故障排查

### 7.1 电脑完全搜不到键盘名

1. **确认真的在广播。** 长按通道键必须**超过 1 秒**；短按开的非配对广播对未配对设备是不可见的。
2. **确认切到了蓝牙模式。** 如果刚插上 USB 没按过 `BLE Host`/`BT1`，还是 USB 模式，蓝牙根本没开。
3. **过了 30 秒窗口。** 重新长按。

### 7.2 能搜到但连不上 / 连上没输入

- **首次配对用了短按。** 短按是非配对广播，新设备连不上。**必须长按**。
- 若之前配过、后来在电脑侧删除了配对记录，键盘侧还留着旧记录，需要**长按重新配对**覆盖。
- 通道串了：确认按的是你要用的那个 `BT1`/`BT2`/`BT3`。

### 7.3 想「恢复出厂 / 清空配对」怎么办

Vial 里的 **`BT Unpair`（解除配对）按钮按了没反应**，用户键 28 同样无效。

**目前清空配对的做法：**
1. 在电脑/手机侧删除该键盘的蓝牙配对记录；
2. 然后长按对应通道键，重新走配对流程。

### 7.4 电池读数不准 / 永远 0%

- 用 USB 供电时电量保护逻辑会被跳过，读数仅供参考。
- 若一直为 0%，按 `WIRING.md` 核对接线。

### 7.5 刚上电 500ms 内蓝牙不响应

键盘启动后需要约 **0.5 秒**下发一次蓝牙配置。

**上电后约 0.5 秒内按蓝牙键可能没反应，属于正常现象。等 1 秒再操作。**

### 7.6 所有蓝牙操作都无效

按 `WIRING.md` 检查键盘与蓝牙桥模块之间的接线：

- 串口是**交叉接线**（键盘 TX → 桥 RX，键盘 RX ← 桥 TX）；
- 波特率 **128000 8N1**；
- **必须共地**。

`TX`/`RX` 接成直连会完全无数据。

## 八、速查卡

```
【首次配对某台设备（通道 N）】
  按住 BT<N>  >1 秒  →  30 秒内在电脑/手机蓝牙里添加设备

【已配对设备重连】
  短按 BT<N>                →  30 秒非配对广播
  或：随便按一个普通键       →  自动重新广播（不会打断已有连接）

【切回 USB】
  按 USB Host（松手才生效）

【切 2.4G】
  短按 2.4G Host（普通）/ 长按 2.4G Host（配对）

【查电量】
  按「用户按键」第 30 个  →  输出 "Bat: N% mV"

【注意】
  默认固件不带蓝牙键，必须先用 Vial「蓝牙/无线」页映射
  只有 BT1/BT2/BT3 有效，BT4/BT5 无效
  短按 = 30~800ms，长按 = ≥1000ms，800~1000ms 无效
  上电 500ms 内不响应蓝牙操作
  10 秒无操作休眠；广播中（30 秒窗口）不休眠
  广播窗口固定 30 秒，超时需重按
  BT Unpair 无效，清配对要去主机侧删记录
```
